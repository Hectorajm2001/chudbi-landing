01

Qué es CHUDBI

CHUDBI es un ERP fiscal para PYMEs mexicanas: contabilidad en partida doble, facturación CFDI 4.0, nómina con parámetros 2026, bancos, CRM, compras, inventarios, impuestos y portales, en 24 módulos que comparten una sola base de datos PostgreSQL.

Incluye a CHUDBOT, un asistente de IA que corre en tu propio equipo (llama.cpp), consulta tus datos con 36 herramientas y busca en 40 documentos normativos indexados.

02

Requisitos

  • Node.js 20 o superior (las imágenes de Docker usan node:20-alpine).
  • PostgreSQL 16 con la extensión pgvector (la usa la búsqueda en documentos normativos).
  • Opcional, para la IA local: un servidor compatible con la API de OpenAI, como llama-server de llama.cpp. Equipo de referencia: RTX 4070 Laptop de 8 GB con 16 GB de RAM.
  • Opcional, para timbrar: una cuenta de Facturapi y tus certificados (CSD) cargados ahí.

03

Instalación con Docker

El repositorio trae un docker-compose.yml con tres servicios: PostgreSQL 16 con pgvector, el backend (que inicializa la base y arranca la API) y el frontend.

docker compose up -d --build

04

Instalación manual

  1. Backend. Instala dependencias, crea el esquema y arranca la API. Las migraciones de database/migrations también se aplican al arrancar.

    cd BETA/sistema-contable-pymes
npm install
npm run init-db
npm run start

  2. Frontend. En otra terminal:

    cd BETA/sistema-contable-pymes/client
npm install
npm run dev

  3. Pruebas. Las 219 pruebas unitarias corren con el runner nativo de Node:

    npm run test:all

06

Primer arranque

La primera vez que un usuario entra, CHUDBI abre el asistente de configuración en cuatro pasos: contraseña y sus políticas, doble factor (2FA), datos de la empresa y confirmación. Al terminarlo se carga el sistema completo.

Para cambiar de razón social usa el selector Empresa de la barra superior: CHUDBI es multiempresa.

07

CHUDBOT, el asistente de IA

Ábrelo desde Asistente IA en el menú o con el botón del robot que aparece en la esquina inferior derecha de cada pantalla.

  • Consulta: saldos bancarios, facturas, clientes, proveedores, inventario, pólizas, estados financieros y nómina.
  • Escribe con permiso: las 20 herramientas que crean o modifican datos piden tu confirmación explícita y quedan en la bitácora de auditoría.
  • Cita la ley: busca en 40 documentos normativos (CFF, LISR, LIVA, LFT, LSS, RMF 2026 y sus anexos, guías del CFDI 4.0) con búsqueda vectorial.
  • Lee archivos: PDF, Word, Excel, PowerPoint, CSV, XML de CFDI, JSON e imágenes, hasta 20 MB.

Desde CHUDBOT Admin revisas el estado del motor, la configuración, los documentos indexados, las conversaciones, la auditoría y las herramientas registradas.

CHUDBOT puede equivocarse: revisa siempre cifras y fundamentos antes de presentar una declaración.

08

Facturación CFDI 4.0

  • Timbrado con PAC: con FACTURAPI_KEY configurada, cada factura se timbra y descargas su XML y PDF.
  • Timbrado asistido en el portal del SAT: CHUDBI prepara la ficha y llena el formulario de «Genera tu factura» en tu navegador, después de que inicias sesión. Nunca recibe tu e.firma ni tu contraseña, y no pulsa «sellar» por ti.
  • Cancelación: con los cuatro motivos vigentes (01 a 04) según el CFF art. 29-A y la RMF 2026.
  • Descarga masiva: requiere la FIEL de la empresa configurada.

10

Seguridad

  • Doble factor (TOTP): actívalo en Usuarios y Roles → Mi perfil y 2FA con cualquier app de autenticación.
  • Roles y permisos: define qué puede consultar o modificar cada perfil.
  • Bitácora: cada operación, incluidas las de la IA, guarda usuario, módulo, IP y fecha.
  • Periodos cerrados: la base de datos bloquea con triggers cualquier cambio en pólizas y facturas de un periodo cerrado.
